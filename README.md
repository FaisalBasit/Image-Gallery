# Image Gallery

A simple responsive image gallery built with HTML, CSS, and JavaScript.

## Features

- Gallery grid displaying multiple images
- Full-screen image preview
- Click an image to open the larger view
- Close control for returning to the gallery
- Browser-based implementation with no backend required

## Run Locally

Open `index.html` in a modern web browser.

## Technology

- HTML5
- CSS3
- JavaScript
